## 使用

1. 手机扫描公开体验码，或浏览器打开体验网址；默认带上小芽怪，也可选择橘皮怪、蓝弹簧或粉饺子；命名后无需钱包即可开始。
2. 点击地面移动，桌面也支持 WASD／方向键。普通行走靠近真实记录节点时，会显示那一刻保存的表情、装扮和礼物；离开后恢复当前外观。中性或正向状态在迈步时切换行走姿势，停下恢复，不覆盖已保存的困难情绪，也不根据地图位置判断心情。有想留下的经历、见闻或念头时，点「路上记一笔」，最多输入 4000 字；点击「记下这一笔」直接保存，无心情、类别或回应选择。服务可用时，点击保存会把本次文字发送给 DeepSeek 理解记录表达的状态并更新表情；可选「仅保存文字」。失败保留草稿，拿不准时保留原表情，不把结果当作心理诊断。
3. 每次主动保存产生一个真实记录节点；同一天可有多段，不记录的日子不生成任务。营火随时开放。手账支持今天、指定日期与日期区间筛选及逐条回看，最近 180 份保存在本机；下一次继续陪同一只角色成长。筛选日期后点击「走进这段回忆」，沿路回看该区间最近十段记录；角色靠近节点会还原当时形象，点击节点会先走到位置、到达后打开原文。回看不增加成长。
4. 每次记录自动留下不同颜色、位置的黏土纪念痕迹，身体展示最近三笔；不会为配道具虚构经历；表情分析仅改变本机视觉状态，不新增链上经历或道德印记。此前已确认的经历与朋友善意对应 10 件 SVG 物件，已获得的物件继续保留并可在「我的 → 身上的故事」整理。角色底图是二维黏土风六状态素材，不是可旋转的 3D 模型。
5. 点「邀请朋友」：已领卡的角色显示「复制送礼邀请链接」；未领卡的角色显示「开启收礼，生成送礼邀请」，确认钱包领取同行卡后才可收礼。无需钱包也可复制「外观预览链接」，但朋友只能查看。每只角色单独绑定同行卡；「我的 → 切换旅伴」标明已开启收礼和卡号。朋友送花、鼓励或星星需钱包确认，主人点「看看朋友的新心意」后显示对应物件；来源纪念物由接收方选择穿戴。

## 虚构示例

打开 [示例旅程](https://little-wayfarer-blitz.vercel.app/?demo=1)，查看最近七天的八段虚构记录。示例在独立浏览器存储空间中保存，不覆盖自己的旅程；示例只读、不可连接钱包或上链。返回「开始我的旅程」即可继续自己的记录。

## 运行

需要 Node.js 20+、npm；预览服务另需 Python 3。

```sh
npm ci
npm run build
npm run dev
```

打开 [本机预览](http://localhost:4173)。`npm test` 运行自动测试，不能代替真实钱包与跨设备验收。

## 记录表情理解

保存流程已接入 DeepSeek `deepseek-flash`，采用 JSON 输出、非思考模式、最多250个输出token。模型仅返回 `mood`（0—5或null）与能在原文找到的 `evidence`，前后端共同校验；不通过则不保存。只提及他人的情绪、否定或转折应区别处理，不确定时保持当前表情。文字不写入链上，节点保存该次表情，旧记录不会自动重新分析。

配置仅在服务端：`AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`、`AI_PROVIDER`、`AI_ACCESS_CODE`、`AI_MAX_REQUESTS`。密钥和体验码不得放入前端、源码或预览链接。默认每IP每分钟最多3次、每进程最多50次，20秒超时，无自动重试。**进程计数不是跨实例的人民币预算硬上限**；实际费用以服务商账单为准，不向公众公开体验码。

本轮3次真实模型调用均通过，合计840个token（含缓存）：难过→2；转折后当前开心→4；只提到朋友难过→null；保存重读后表情一致。记录见 `submission/semantic-ai-verification.json`。122项自动检查和构建通过；实际浏览器里的保存、体验码及画面切换尚待验收。

接口参数依据 [DeepSeek JSON输出](https://api-docs.deepseek.com/zh-cn/guides/json_mode/) 和 [思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。
