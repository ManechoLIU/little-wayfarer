# 小旅伴 · 还在路上 / Little Wayfarer

把普通的一天走成小旅行，再把走过的经历，变成彼此身上的纪念物。

Monad Blitz Shanghai 2026 参赛原型。[作品 #440](https://mojo.devnads.com/projects/440) 已提交，关联活动 #17，当前待审核；提交页已由真实浏览器核对三张截图、完整介绍、体验及源码链接。公开网站与 GitHub 已可访问。旧合约上的角色出生及双钱包送花已验收。前端版本 `aba11f7` 已发布，Vercel 部署 `dpl_DU7QUBQi1y7t6XiJvPjeMtAnBR3A` 为 READY，公开别名已指向该部署。当前构建及 100 项测试通过，手机入口与叠加布局已检查；新分享入口和长按手势的真实浏览器验收因安全检查不可用暂未完成。V2 合约已部署并核对运行代码一致，真实重复送礼仍待验收。

## 使用

1. 手机扫描公开体验码，或浏览器打开体验网址；默认带上小芽怪，也可选择橘皮怪、蓝弹簧或粉饺子；命名后无需钱包即可开始。
2. 点击地面移动，桌面也支持 WASD／方向键。有想留下的经历、见闻或念头时，点「路上记一笔」，最多输入 4000 字；点击「记下这一笔」直接保存，无心情、类别、回应或分析步骤，不调用模型、不替用户判断情绪。
3. 每次主动保存产生一个真实记录节点；同一天可有多段，不记录的日子不生成任务。营火随时开放。手账支持今天、指定日期与日期区间筛选及逐条回看，最近 180 份保存在本机；下一次继续陪同一只角色成长。筛选日期后点击「走进这段回忆」，沿路回看该区间最近十段记录；角色靠近节点会还原当时形象，点击节点会先走到位置、到达后打开原文。回看不增加成长。
4. 每次记录自动留下不同颜色、位置的黏土纪念痕迹，身体展示最近三笔；不会为配道具虚构经历或改变用户心情。此前已确认的经历与朋友善意对应 10 件 SVG 物件，已获得的物件继续保留并可在「我的 → 身上的故事」整理。角色底图是二维黏土风六状态素材，不是可旋转的 3D 模型。
5. 点「邀请朋友 → 复制邀请链接」即可分享角色，无同行卡时分享的是当时外观快照，朋友只能查看。需要收礼时，再展开「让朋友留下链上礼物」连接 Monad Testnet 钱包领取同行卡；此后复制的是可互动链接。朋友送花、鼓励或星星需钱包确认，主人点「看看朋友的新心意」后显示对应物件；也可赠送有来源的经历纪念物，由接收方确认穿戴一件或摘下。

## 虚构示例

打开 [示例旅程](https://little-wayfarer-blitz.vercel.app/?demo=1)，查看最近七天的八段虚构记录。示例在独立浏览器存储空间中保存，不覆盖自己的旅程；示例只读、不可连接钱包或上链。返回「开始我的旅程」即可继续自己的记录。

## 运行

需要 Node.js 20+、npm；预览服务另需 Python 3。

```sh
npm ci
npm run build
npm run dev
```

打开 [本机预览](http://localhost:4173)。`npm test` 运行自动测试，不能代替真实钱包与跨设备验收。

## 钱包与边界

连续三次送花、累计渲染、存档读取后保留三朵、旧记录仍显示当时零朵或一朵，已通过本地 EVM 与实际存档／渲染模块的组合测试；该证据不能代替 Monad 测试网的双钱包真实验收。

- 仅支持 Monad Testnet，链 ID 10143。发送纪念物须由来源旅伴主人签名，且来源确已记录对应印记的首次章节；接收方主人控制穿戴。默认配置已改为 V2 合约，支持反复赠送。已有旧版同行卡仍使用原合约的终身一次限制，需要在邀请页换用新版卡。
- `encourage`：花 `0`、鼓励 `1`、星 `2`、彩纸弹 `3`。彩纸弹仅提供 12 秒视觉反馈，不改长期情绪或印记。邀请展示页每 5 秒读取链上状态；旧版本同一 Chrome 内双账户送花、双方显示和主人刷新保留已验收，独立设备仍待验收。
- V2 源码已加入重复赠送及 `getGiftCounts` 链上累计数量，对应前端与叠加展示已发布；V2 已部署并核对源码对应运行代码；旧地址不支持新增接口。新版仍须换卡及真实钱包重复赠送验收。
- 钱包不等于真人，链上记录不证明现实经历。不含实时多人同屏、聊天、经济系统、NFT 买卖或赚钱；交易需测试 MON 支付网络 Gas，没有代币授权或资金托管。
- 正文默认仅存本机，不上链；浏览器存储不等于加密保险箱。清理浏览器会丢失本机记录，链上确认也不会备份正文。公开记录包含钱包及经历编号等信息。真实模型分析接口保留，但用户已选择暂不启用付费，当前记录页不分析、不调用模型服务。未来接通必须在发送正文前明确告知用户。
- 本机与链上章节分开标识；最多 20 章合并确认，仅保留最近 100 章本机经历，缺少早期章节时停止补写。照片仅支持本地预览及导入已生成的六状态图，无自动会员生图、无限 AI 生成或聊天。
