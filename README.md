# 小旅伴 · 还在路上 / Little Wayfarer

给不完美的自己，捏一个奇怪鲜活的小角色。经历会改变神态，回应会留下成长，同行者可以送来善意。受挫可以恢复，休息不会清空成长；长大也不必变成标准漂亮。

Monad Blitz Shanghai 2026 参赛原型。首版包含三种原创多巴胺配色黏土风角色、四组配色、六种状态、六种经历及十二种回应、本机手账和回放。图像是二维黏土渲染素材，不是可旋转的3D模型。

## 使用

1. 命名并选择角色，无需钱包即可开始。
2. 选择经历与回应，观察变化，回看或导出手账。
3. 连接 Monad Testnet 钱包，确认出生和章节交易。
4. 分享同行链接，让另一钱包留下一朵花、一句加油或一颗星。每个其他钱包对每只旅伴仅能留一次。
5. 旅伴主人点击“看看新善意”读取链上回应。

## 运行

Node.js 20+。`npm ci`，`npm run build`，`npm run dev`，打开 http://localhost:4173 。`npm test`运行领域、合约和持久化边界测试。

合约为 contracts/Wayfarer.sol。仅支持 Monad Testnet，链ID 10143。可在网页“链上设置”部署并保存合约地址。部署与记录均由钱包持有人确认，仅涉及测试网 Gas；没有代币授权、资金托管、管理员或角色转让。

## 记录与边界

- 本机章节与钱包已确认章节分别标识。按顺序最多20章合并一次交易。
- 仅保存最近100章本机故事；首次上链前超过100章会停止补写，避免编造缺失历史。
- 不覆盖另一标签页更新；链上章节与本机确认游标不一致时停止，不把另一条故事误标上链。
- 本机内容不跨设备同步。清理浏览器会删除本机手账；导出可留存JSON。专属角色图保存在IndexedDB，不包含在手账JSON里。
- 默认角色可直接体验。可导入有权使用的3列×2行六状态图片。网站没有自动照片生成服务，不接收或保存API密钥，不会调用访客或作者的Codex会员。参考图仅本地预览。
- 链上只记录钱包、出生参数、经历/回应编号、状态和印记。它不证明现实行为、真人身份或现实情绪，也不作道德评分。
- 本地EVM测试通过不等同于真实测试网验收；正式部署地址、公开网址及验收状态以参赛提交资料为准。
