# 小旅伴 · 还在路上 / Little Wayfarer

把普通的一天走成小旅行，再把走过的经历，变成彼此身上的纪念物。

Monad Blitz Shanghai 2026 参赛原型。当前构建和 64 项自动测试通过；公开体验网站与 GitHub 源码已可访问；真实测试网部署和双人闭环尚未验收。用户暂不决定参赛，作品未提交。

## 使用

1. 手机扫描公开体验码，或浏览器打开体验网址；命名并选择橘皮怪、蓝弹簧或粉饺子，无需钱包即可开始。
2. 点击地面移动，桌面也支持 WASD／方向键。有想留下的经历、见闻或念头时，点「路上记一笔」，最多输入 4000 字；确认可修改的经历候选，也可只保存文字。默认本地规则建议，不冒充 AI 理解。
3. 每次主动保存产生一个真实记录节点；同一天可有多段，不记录的日子不生成任务。营火随时开放。手账支持今天、指定日期与日期区间筛选及逐条回看，最近 180 份保存在本机；下一次继续陪同一只角色成长。筛选日期后点击「走进这段回忆」，沿路回看该区间最近十段记录；角色靠近节点会还原当时形象，点击节点会先走到位置、到达后打开原文。回看不增加成长。
4. 确认经历并保存后，相关物件自动出现在角色身上，无需先进入背包；自身最多叠加三件，之后仍可整理。每次记录还会自动留下黏土经历纹，纯文字记录用脚印表示，身体展示最近三笔。经历与收到的善意对应 10 件 SVG 物件。角色底图是二维黏土风六状态素材，不是可旋转的 3D 模型。
5. 自愿连接 Monad Testnet 钱包，确认出生及经历，再分享自己的旅伴链接。朋友可赠送有来源的经历纪念物；接收方自行确认穿戴一件或摘下。

## 虚构示例

打开 [示例旅程](https://little-wayfarer-blitz.vercel.app/?demo=1)，查看最近七天的八段虚构记录。示例在独立浏览器存储空间中保存，不覆盖自己的旅程；示例只读、不可连接钱包或上链。返回「开始我的旅程」即可继续自己的记录。

## 运行

需要 Node.js 20+、npm；预览服务另需 Python 3。

```sh
npm ci
npm run build
npm run dev
```

打开 [本机预览](http://localhost:4173)。`npm test` 运行自动测试，不能代替真实钱包与跨设备验收。

## 钱包与边界

- 仅支持 Monad Testnet，链 ID 10143。发送纪念物须由来源旅伴主人签名，且来源确已记录对应印记的首次章节；每发送钱包对每只目标旅伴只能送一次。接收方主人控制穿戴。
- `encourage`：花 `0`、鼓励 `1`、星 `2`、彩纸弹 `3`；每个其他钱包对每只旅伴终身只能选送一次。彩纸弹仅提供 12 秒视觉反馈，不改长期情绪或印记。邀请展示页每 5 秒读取链上状态，真实跨设备反馈仍待验收。
- 钱包不等于真人，链上记录不证明现实经历。不含实时多人同屏、聊天、经济系统、NFT 买卖或赚钱；交易需测试 MON 支付网络 Gas，没有代币授权或资金托管。
- 正文默认仅存本机，不上链；浏览器存储不等于加密保险箱。清理浏览器会丢失本机记录，链上确认也不会备份正文。公开记录包含钱包及经历编号等信息。真实模型分析接口已实现；用户已选择暂不启用付费分析，当前不调用模型服务；接通后，用户主动分析的正文将发送给配置的模型服务，界面必须明确提示。
- 本机与链上章节分开标识；最多 20 章合并确认，仅保留最近 100 章本机经历，缺少早期章节时停止补写。照片仅支持本地预览及导入已生成的六状态图，无自动会员生图、无限 AI 生成或聊天。
