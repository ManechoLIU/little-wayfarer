# 小旅伴 · 还在路上

一句话：把普通小小的我们，捏成一只会把经历长在身上的丑东西。

每个人选择一只多巴胺配色的奇怪黏土角色，带它经历探索、失败、孤单、犯错、帮助别人和休息。不同回应会改变神态，留下可回看的故事与成长印记。休息和难过不会抹去成长，变好也不必变成标准漂亮。

Monad让出生、经历选择与同行者留下的善意成为可核验的公开足迹。主人决定自己的道路，另一钱包可以留下一朵花、一句加油或一颗星。角色状态由固定规则计算，没有金融投机、付费抽取或现实道德评分。

演示顺序：创建角色 → 经历挫折并休息 → 犯错后修补 → 回看变化 → 钱包确认出生与章节 → 分享链接 → 另一钱包送来善意 → 主人刷新背包。

首版范围：三种默认角色、四组配色、六状态；本机体验无需钱包，链上操作由持有人确认。自定义六状态角色图支持本地导入；自动照片生成不在本次交付范围。图像是二维黏土风渲染。
