# 小旅伴 · 还在路上

一句话：把普通的一天走成小旅行，再把走过的经历，变成彼此身上的纪念物。

提交状态：[作品 #440](https://mojo.devnads.com/projects/440) 已提交、待审核，关联活动 #17。真实浏览器已核对三张截图、完整介绍、体验及 GitHub 链接；用户已确认提交完成并继续开发。

## 给谁，解决什么场景

面向想留住普通经历、又不愿写长日记的人。比如方案被否后，随手写「今天有点受挫，但还是重新改了一遍」。输入后直接保存，角色留下中性的黏土纪念痕迹，路上新增一处可回看的记忆；不分析情绪，不要求选择类别。一次记录可以很短，同一天可有多段；没有记录的日子不生成任务。按今天、某天或时间区间回看，同一只角色、成长痕迹和本机手账持续积累。该定位尚无用户访谈或留存证据，不承诺情绪疗效。

## 玩法与 Monad 的作用

点地面或用 WASD 自由行走，随时记录沿途的想法和见闻；只有真实保存的记录才成为节点，营火始终开放。文字记录自动留下身体纪念痕迹；此前获得的经历与朋友物件保留并可整理。角色是二维黏土风素材，不是可旋转的 3D 模型。日期筛选后可走进所选区间的回忆，经过节点切换历史外观；点击节点先走到位置，到达后展开原记录。

社交围绕经历来源：只有来源旅伴主人，且确已在链上获得对应印记，才能把它作为纪念物送给另一只旅伴。物件可追溯来源角色、首次章节与赠送记录；接收方主人决定穿戴一件或摘下。当前已部署旧合约限制每发送钱包对每只目标只可送一次；取消次数限制及数量叠加是本地 V2 工作，尚未部署或完成真实验收。

钱包提供来源签名与控制权限，Monad 提供独立可核验记录；普通数据库也能做类似体验，链不是个人手账的必要条件。不涉及买卖、赚钱或真人认证，仅需测试 MON 支付网络 Gas。朋友也可一次性选择送花、鼓励、星或 12 秒彩纸弹；彩纸弹不改变长期状态。

## 90 秒双人演示脚本

演示前准备两台设备、两只已出生的旅伴及有测试 MON 的钱包；链上确认耗时另计。

1. A 输入一段经历并直接保存，看到身体痕迹与新增节点，再走近节点回看。
2. A 连接钱包并分享旅伴链接，B 用另一钱包打开，选择花、鼓励、星或彩纸弹并确认。
3. A 更新朋友心意，观察角色物件变化与刷新后保留；旧版本双钱包送花已有真实验收，其他互动及独立设备仍须定向验证。
4. 来源纪念物的赠送、穿戴为后续真实验收项；不把文字记录直接保存等同于已上链经历。
